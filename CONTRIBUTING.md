# Contributing to NotesLocker

Thank you for your interest in contributing to NotesLocker! 🎉

We welcome bug fixes, documentation improvements, UI enhancements, performance optimizations, and new feature suggestions.

---

## Getting Started

### 1. Fork the repository

Click the **Fork** button on GitHub.

### 2. Clone your fork

```bash
git clone https://github.com/<your-username>/NotesLocker.git
cd NotesLocker
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env` file using the variables described in the project documentation.

### 5. Start the development server

```bash
npm run dev
```

---

# Branch Naming

Use descriptive branch names.

Examples:

```
feature/add-search
feature/dark-mode
fix/login-error
docs/update-readme
docs/setup-guide
refactor/firebase-config
```

---

# Commit Message Guidelines

Follow a simple conventional format.

Examples:

```
feat: add note search
fix: resolve login redirect issue
docs: update contributing guide
refactor: simplify firebase initialization
style: improve button spacing
```

---

# Code Style

- Use meaningful variable names.
- Keep components small and reusable.
- Remove unused imports.
- Keep formatting consistent.
- Avoid unnecessary comments.
- Test your changes before opening a Pull Request.

---

# Pull Request Checklist

Before opening a Pull Request:

- [ ] Code builds successfully
- [ ] No console errors
- [ ] Documentation updated (if needed)
- [ ] Changes tested locally
- [ ] Commit messages follow project guidelines
- [ ] Pull Request targets the `main` branch

---

# Reporting Bugs

Include:

- Description
- Steps to reproduce
- Expected behavior
- Actual behavior
- Screenshots (if applicable)

---

# Suggesting Features

Please include:

- Problem statement
- Proposed solution
- Additional context

---

# Code of Conduct

Be respectful and constructive.

We value:

- Respectful communication
- Helpful code reviews
- Beginner-friendly discussions
- Inclusive collaboration
